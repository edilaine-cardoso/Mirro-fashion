# Mirro Fashion - PHP Version

Versão básica do projeto Mirro Fashion desenvolvida em PHP puro.

## Tecnologias Utilizadas

- PHP (procedural)
- HTML5
- CSS3

## Estrutura do Projeto

```
index.php           - Página inicial
produto.php         - Página de detalhes do produto
sobre.php           - Página sobre
cabecalho.php       - Componente de cabeçalho
rodape.php          - Componente de rodapé
css/                - Folhas de estilo
img/                - Recursos de imagem
appsettings.json    - Configurações
```

## Requisitos

- PHP 7.4 ou superior
- Servidor web (Apache, Nginx)

## Instruções de Execução

1. Clone o repositório
2. Configure um servidor PHP local
3. Acesse a aplicação no navegador
