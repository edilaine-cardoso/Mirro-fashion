# Mirro Fashion - .NET Blazor

Aplicacao Mirro Fashion desenvolvida em ASP.NET Core com Blazor.

## Tecnologias Utilizadas

- ASP.NET Core 8.0+
- Blazor Server
- C#
- Razor Components

## Arquitetura

```
LearnBlazor.csproj  - Arquivo de projeto
Program.cs          - Configuracao da aplicacao
Components/         - Componentes Razor
wwwroot/            - Assets estaticos
Properties/         - Propriedades do projeto
appsettings.json    - Configuracoes de aplicacao
```

## Requisitos

- .NET 8.0 SDK ou superior
- Visual Studio 2022, Visual Studio Code ou JetBrains Rider

## Instalacao e Execucao

1. Clone o repositorio
2. Navegue ate a pasta do projeto
3. Execute `dotnet restore` para restaurar as dependencias
4. Execute `dotnet run` para iniciar a aplicacao
5. Acesse a aplicacao em https://localhost:5001

## Estrutura de Componentes

Os componentes Razor estao organizados na pasta Components/ e permitem criar interfaces interativas com atualizacoes em tempo real.

## Versoes Anteriores

Para acessar a versao em PHP (versao basica), consulte a branch `feat/php-version`.
